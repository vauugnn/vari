# Vari beyond SPSS: product brief

Vari keeps SPSS's layout, syntax, and file formats (.sav / .spv) so what a professor sees is
unchanged. On top of that, additions SPSS does not have. All are additive and optional.

## Features
1. **Plain-English results + APA export.** An "Interpret" note under common test tables
   (t-test, correlation, chi-square, ANOVA) written by rules, not a model, so it is always
   consistent with the numbers. "Copy as APA" puts an APA-style table on the clipboard. *(Copy as APA: done.)*
2. **Test chooser.** A short question flow ("how many groups? what kind of data?") that opens the
   right dialog and warns when an assumption fails.
3. **Version history.** Google-Docs-style, local only. See `technical-brief.md`.
4. **Autosave and crash recovery**, built on version history. Plus deeper undo for data edits.
5. **Charts.** Colour-blind-safe palette option, export as PNG / SVG / PDF.
6. **Free, no licence, cross-platform** stated in About.

## Non-goals
No cloud sync, no accounts, no telemetry. History never leaves the machine.
